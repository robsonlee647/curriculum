Stages 1 – 2

Frontend

Start with the language itself, no framework in the way — then move to Next.js, where routing, components, and data-fetching come together.

Stage 1

JavaScript Foundations

A bare HTML file and a script tag. The only goal is comfort with core JavaScript and the DOM before a framework adds its own conventions on top — plus a minimal Node server to see the request/response cycle from the outside.

Stage 2

Next.js

A learning-focused Next.js 14 app with two paths through the same material — pick whichever fits how you learn.

📘 Simple path

Four short lessons, best with some prior React/Next.js exposure.

  • 1. Pages & routing — /about
  • 2. Interactive components — /counter
  • 3. Lists & forms — /todos
  • 4. API calls — /api-example

📕 Complex path

A self-paced 3-week arc that ends in two shipped mini-projects.

  • Week 1 — foundations: structure, routing, styling, state, forms
  • Week 2 — API calls, components, then real builds: a weather app and a note-taking app
  • Week 3 — polish, testing, docs, and deploy
