Mentorship Curriculum

A hands-on path to full-stack developer, one real project at a time.

Seven stages, each a working codebase — from tool setup to a deployed marketplace app built with Next.js, NestJS, PostgreSQL, and Firebase Auth. Built by Robson Lee to mentor new developers through practice, not slides.
