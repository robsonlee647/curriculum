Before any app code, the machine needs to be ready: an editor, version control, a runtime, and a database — plus the AI pairing setup used throughout the curriculum.

Tooling checklist

Installed once, used across every later stage.

  • IntelliJ IDEA (Ultimate) — primary editor for both frontend and backend work.
  • GitHub Desktop — visual git workflow alongside the CLI.
  • Notion — notes and progress tracking through the curriculum.
  • Discord — async mentor check-ins.
  • Claude Code — installed as a CLI and as an IntelliJ plugin, used as a pairing tool from stage 1 onward.
  • Homebrew — package manager for everything that follows on macOS.
  • Node.js via nvm — the JavaScript runtime, version-managed so it can be bumped per stage.
  • PostgreSQL 16 — installed and running locally ahead of stage 4, where persistence is introduced.
Full install commands — including shell configuration and version checks for each tool — live in the prerequisites reference in the setup repo.
